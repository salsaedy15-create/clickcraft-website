# ClickCraft AI MVP

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL Vite prints.

## What is included
- Responsive SaaS dashboard
- Landing page
- AI marketing tool UI
- Demo generation mode
- Saved content
- Business profile
- Usage tracking
- Settings
- Mobile navigation

The AI calls are intentionally represented by demo mode. Add a server-side AI API route and environment variable before production. Never expose an API key in browser code.
